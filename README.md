# Elemailer Lite

Free WordPress plugin that lets users design form emails with Elementor. The WordPress.org listing text is in `readme.txt`.

## Development

- AI agents: start with [AGENTS.md](AGENTS.md) and `docs/tasks/current-task.md`.
- Humans: see [docs/local-setup.md](docs/local-setup.md) for local setup, [docs/architecture.md](docs/architecture.md) for how the code is wired, and [docs/core-changes-needed.md](docs/core-changes-needed.md) for the planned fix list.
- Work on a branch and open a pull request. Never commit to `master`, and never push a tag unless you intend to deploy to WordPress.org (see [docs/release-process.md](docs/release-process.md)).
