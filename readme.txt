Elemailer is an Elementor addon to create Email templates. It gives you the most flexible design environment to design emails through drag and drop builder- Elementor. Design beautiful emails without any code

You must have [Elementor Page Builder](https://wordpress.org/plugins/elementor/) installed. To design your email template.

You should have [Contact Form 7](https://wordpress.org/plugins/contact-form-7/) installed & activated if you want to design cf7 email templates with Elemailer

You should have [Elementor Pro](https://elementor.com/pro/) installed if you want to use elemailer tempalte in your Elementor Pro's forms response


== Description ==
<h3>
Elemailer -Best drag & drop Email design Plugin for WordPress
</h3>

Elemailer Lite is an email template & campaign builder based on Elementor page builder. 

This plugin gives you the facility of override different WordPress Form plugin's email template. No more HTML code writing inside your forms to design good-looking emails. 

==List of Supported Form Plugins: ==

[Contact Form 7 :](https://wordpress.org/plugins/contact-form-7/) Design your contact form 7 emails without any code. Find out more: [How to Design Contact form 7 Email template? ](https://elemailer.com/now-you-can-edit-your-contact-form-7-email-using-elementor/) 

[Elementor Pro's Form Widget :](https://elementor.com/pro/) You can design elementor pro's form widget's email, email2 layout with Elemailer Lite. 

== Features ==

* You can create email templates with easy to use, drag and drop elementor editor.
* Facility to use it as form submission template for Elementor Pro's Form Widget. 
* Marketers can use it easily for sending our beautiful emails to clients who subscribes.
* Supports 3 template creation at max in the lite version.

== Installation ==

1. Upload the plugin folder after extracting it to the "/wp-content/plugins/(the folder of the extracted plugin)" directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to Elemailer -> Form Templates from the WordPress admin dashboard. Create a new template and design it with the Elementor page builder editor. Finally, Go to a page and drag the 'Form' widget of the Elementor. You will get an option to use our templates on email and email2 form submission action.

== Frequently Asked Questions ==

= How to use elemailer lite's template =

Our elemailer lite creates form templates under wp-admin> Elemailer> Forms. With each form, it has a shortcode that can be used with supported plugins ( list above ). 
For Elementor Pro you simply need to create our form template > Go to the elementor page where you have the Elementor pro's form widget > When you add the after submit action ( Email & Email2 ) you will see option to select our template at the bottom of each Email & Email2. 

= Can I create more than 3 templates with the lite version? =

With Elemailer Lite you can only create 3 email template for your forms. 

= Can I remove footer Branding and add my own? =

In the lite version, you can add your own Branding if you want but you can't remove our footer branding. But you can get Elemailer ( The pro version from our site ) and remove the branding. This is a practice done in any platform/plugin.
