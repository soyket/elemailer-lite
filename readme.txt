This wordpress plugin gives you most flexiable design environment to design email templates. Currently, You can design elementor's form response by using it. 

You must have [Elementor Page Builder](https://wordpress.org/plugins/elementor/) installed. For design your email template.
You must have [Elementor Pro](https://elementor.com/pro/) installed and forms created. Then You will get option for using our templates.


== Description ==

This plugin gives you the facility of override elementor default form email template. You can create template by usgin it and use to send as form submission email.

* You can create template here with elementor editor.
* Facility to use it as form submission template.


For more details :[Elemailer](https://elemailer.com/).

== Installation ==

1. Upload the plugin folder after extracting it to the "/wp-content/plugins/(the folder of the extracted plugin)" directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to Elemailer -> Form Templates from wordpress admin dashboard. Create a new template and design it with elementor page builder editor. Finally, Go to a page and drag 'Form' widget of elementor. You will get a option to use our templates on email and email2 form submission action.
